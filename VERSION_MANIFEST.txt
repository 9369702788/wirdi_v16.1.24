WIRDI v243 -- adds a 5th (bonus, best-effort) radio source
================================================================================

Builds on top of v242 -- apply AFTER v242, do not skip it.

Files in this package:
1) lib/core/models/radio_station.dart
   - New factory: RadioStation.fromQuranStationsJsFields()

2) lib/core/services/radio_service.dart
   - New _fetchQuranStationsJs(): fetches + regex-parses a public GitHub
     Gist ("QuranStations.js") as a 5th station source
   - Wired into the EXISTING merge pipeline in _doRefresh() with the same
     try/catch safety net as the other 4 sources -- if this gist ever
     goes offline or changes format, nothing else in the app is affected

IMPORTANT HONESTY NOTE:
- "qrRadio" (the other GitHub project you found) was investigated and is
  NOT a separate data source -- it's a UI built on top of mp3quran.net /
  the Uthumany API, BOTH of which Wirdi already fetches from directly.
  Adding it would have been pure duplication, so it was intentionally
  skipped.
- "QuranStations.js" is hosted as one person's GitHub Gist, not a
  maintained repository/package. It's included as a bonus 5th source
  precisely BECAUSE the existing merge pipeline already treats every
  source as optional/best-effort -- but it is inherently less reliable
  long-term than the other 4 (official APIs/repos). If it stops working
  someday, tell Sigma and it can simply be removed with a one-line edit
  (nothing else depends on it).
